# 🏢 Enterprise Workforce Analytics Pro

A **professional-grade employee analytics dashboard** built with modern web technologies by **Nitin Rahane**. This comprehensive platform provides enterprise-level workforce insights, performance tracking, and data-driven HR analytics.

- **Dark/Light Mode Support** with persistent preferences

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/your-username/enterprise-workforce-analytics-pro.git

# Navigate to project directory
cd enterprise-workforce-analytics-pro

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📊 Dashboard Features

### **KPI Monitoring**
- Total Employees with growth trends
- Average Salary with compensation analysis
- Performance Scores with team comparisons
- Retention Rates with risk indicators
- Satisfaction Metrics with department breakdowns
- Productivity Tracking with efficiency insights
- Engagement Levels with improvement suggestions
- Project Completion Statistics

### **Data Visualizations**
- **Department Performance Analysis**: Combined bar and area charts
- **Skill Level Distribution**: Interactive pie charts with percentages
- **Performance vs Satisfaction**: Scatter plot correlations
- **Performance Radar**: Multi-dimensional performance metrics
- **Salary Analysis**: Horizontal bar charts by department
- **Productivity Trends**: Combined charts with correlation analysis

### **Interactive Features**
- **Department Filtering**: Filter all data by specific departments
- **Data Export**: Download analytics data in JSON format

## 🎨 Design System

### **Color Palette**
- **Primary**: Blue (#3B82F6) - Navigation and primary actions
- **Success**: Green (#10B981) - Positive metrics and confirmations
- **Warning**: Yellow (#F59E0B) - Attention and moderate alerts
- **Danger**: Red (#EF4444) - Critical alerts and negative metrics
- **Info**: Purple (#8B5CF6) - Information and secondary actions

### **Typography**
- **Headings**: Inter font family with bold weights
- **Body Text**: System font stack for optimal readability
- **Code**: Monospace for technical content

## 📱 Responsive Design

| Breakpoint | Description | Features |
|------------|-------------|----------|
| **Mobile** | < 640px | Stacked layout, simplified navigation |
| **Tablet** | 640px - 1024px | Grid layouts, condensed charts |
| **Desktop** | > 1024px | Full feature set, multi-column layouts |
